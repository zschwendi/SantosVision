# Experimental reprojection paths — October 11, 2026

Staged native implementation of the three reviewed alternatives to one quad per source pixel: a retained source-anchor fullscreen copy, an independent analytic two-eye anchor probe, and a conservative adaptive tile mesh, plus the Swift side of the atomic stereo pair bridge. Every path is **off by default**; with no flag set the renderer encodes exactly the legacy draw with the legacy uniforms, present-time anchor and acknowledgement. Claude Desktop Fable 5.1, Extra effort, implemented the Swift and Metal under root coordination; Sol owns the Rust producer and `WorldBridge.h`. This record describes source that root validates; it makes no performance, headset, matched-stereo or 4K60 claim.

## Flags

| Flag | Default | Effect |
| --- | --- | --- |
| `MUGUET_COMPOSITOR_SOURCE_ANCHOR_COPY=1` | off | Per drawable, when eligible: label the drawable with the retained ARKit anchor of the pose the source was rendered at and present each eye with one fullscreen triangle that re-samples colour and reconstructs depth per pixel; otherwise the mesh paths. |
| `MUGUET_COMPOSITOR_SOURCE_ANCHOR_COPY_ALLOW_SYNTHETIC=1` | off | Simulator only: allow the copy for actual game frames when the retained pose has no ARKit anchor (pose fixture). Proves conversion and plumbing, not display adjustment. |
| `MUGUET_COMPOSITOR_ANCHOR_PROBE=1` | off | Replace game content with a frozen analytic scene rendered into two coherent source eye textures from one retained anchor; present it through the mesh or the copy. `_MODE` = `mesh`, `copy` or `alternate` (default, A/B/A every `_SWITCH_SECONDS`, default 5); `_HOLD_FRAMES` (default 8) controls source age; `_SCALE` (default 1) the source size relative to the viewport; `_MAX_MIB` (default 384) caps the probe's retained texture bytes. |
| `MUGUET_COMPOSITOR_ADAPTIVE_MESH=1` | off | 8x8 tile classification on the GPU; accepted tiles draw the same 32-triangle fan through 96 static indices and 33 unique vertices, every other tile the legacy per-texel strip, through two indirect draws. `MUGUET_COMPOSITOR_ADAPTIVE_TOLERANCE_ULP` (default 16) is the stated plane tolerance. |
| `MUGUET_XR_PAIRED_RENDER=1` | off | Two-view drawables first ask `sv_world_acquire_pair` for one atomic pair (0 ready, 1 not ready, -1 invalid); any rejection releases both tokens exactly once and falls back to independent acquisition. |
| `MUGUET_XR_ANCHOR_RETAIN_FRAMES` / `_SECONDS` | 64 / 2 | Bounds of the retained-anchor cache. Counters report hits, misses by cause, evictions and invalidations. |
| `MUGUET_COMPOSITOR_CORNER_PRECOMPUTE=1` | off | Unchanged exact corner precompute (experiment B). Precedence per eye: copy, adaptive, precompute, legacy. |

## What is wired

- **Anchor retention** (`XRHeadTracking.swift`). The compositor already assigns the native head frame; the renderer now hands the actual `DeviceAnchor`, the eye request frame and the per-eye transforms and projections to the same submission, and the cache keys them by the exact consumed `head_frame`. `request_frame` is retained alongside and must match the lease; it is never the anchor key. Synthetic simulator poses are retained with `anchor == nil`. The cache is invalidated on recenter, suspend, an untracked submission after a tracked one, and renderer stop. No anchor is ever constructed from matrices or re-queried from an old timestamp.
- **Copy eligibility** (`GameWorldRenderer.swift`, `GameWorldSourceCopy.swift`). One anchor per drawable, so every view's source must share one head frame and one request; two views require a validated atomic pair. The retained pose must reproduce each eye's `game_from_eye` through the lease's `game_from_stage` within tolerance, and its projection must match up to the forward-Z depth-row flip. The lattice gate requires the viewport extent to equal the source size, an integral viewport origin, the identical projection (hence identical rays and depth range), and the present head-from-eye transform equal to the one retained with the pose within a rigid tolerance of 1e-5 in rotation and 0.1 mm in translation, because a changed eye calibration moves the ray origin under the labelled anchor; anything else uses the mesh with a counted reason. The shader reconstructs depth per pixel from source depth and the two projections, writes sky as 0, discards non-finite or out-of-range depth, and applies the Bayer near fade from the present head's position relative to the source eye while geometry and depth stay source-anchored.
- **Analytic probe** (`GameWorldAnchorProbe.swift`, `GameWorldProbe.metal`). Ground, a wall with a hard depth edge in front of a farther wall, sky as clear depth, and a near panel 0.30 m in front of the head rendered into colour plus R32Float NDC depth per eye with the drawable's own view transforms and projections. Texture sets are leased to every command buffer that reads them and returned on completion; the held set is never a write candidate and the writer set is leased before any eye is encoded. The probe never acquires a native lease, never calls `sv_world_complete_frame`, never emits `.presented`, and times itself in a separate `GameCompositorProbe` log namespace with `source_kind` `analytic` or `synthetic`.
- **Adaptive mesh** (`GameWorldAdaptiveMesh.swift`, `GameWorld.metal`). Classification accepts a tile only when all 64 covered depths and the 10x10 halo are valid and non-clear, all 81 geometric corners qualify under the legacy `qualifiedCornerDepth`, every corner, covered centre and halo centre lies on one affine NDC plane within the tolerance, and no corner is behind the eye, outside the clip depth range or inside the near-fade band. Border and partial tiles always fall back. The fan now uses one centre and 32 perimeter vertices with static indices in the original triangle order; perimeter vertices use the same `continuousCornerDepth` values as fine neighbours, so coarse/fine seams share identical vertices. Two padded 32-byte indirect records hold the indexed fan and unchanged strip fallback; scratch sets are bounded (6 sets, 4 MiB each), leased on acquisition and returned on completion, and counters are read from the shared 64-byte argument copy after completion.
- **Pair bridge** (`GameWorldSourceCopy.swift`). Direct call to the committed `sv_world_acquire_pair` with the imported `SVWorldPair`; the 592-byte layout is checked at runtime. Validation rejects a zero scene epoch, shared or zero leases, swapped eye indices, mixed head or request frames, mixed presentation time, mixed size and differing `game_from_stage`. The producer side is Sol's and remains unproven here.

## Verification

Root executes; nothing here was built or run by the implementer.

- `scripts/reprojection-static-check.sh`: Swift 6 strict typecheck (simulator, device, non-runtime), offline Metal compile of both shader files for three SDKs, harness build and CPU-only selfcheck. Fail-closed exit status per step.
- `target/verification/reprojection-implementation-v1/build-harness.sh`: compiles the standalone harness with the production `AdaptiveScratchPool`, pure source checks and `XRRetainedEyeView` extracted verbatim.
- `target/verification/reprojection-implementation-v1/run-gpu-batch.sh <run-id>`: GPU slot owner only. Selfcheck, then parity, then timing, into `runs/<run-id>/`.
- Harness fixtures (29): plane identity reverse and forward, slope, yaw, lateral, lateral forward with roll, near-plane crossing, interior island, shallow step at a tile boundary, step inside a tile, sky with foreground, sky islands, sky-only rotated, invalid islands, 37x23 borders, 3x3, fade transition, fade visible, noise, affine reverse and forward, and copy-eligible plane reverse and forward, slope, step with sky and invalid, noise, fade, sky with foreground, fade translated toward and away.
- Gates: the legacy-OFF path must be bit-identical to the frozen original in colour, depth and written-pixel mask; candidates must be within 1 colour LSB and 4 depth ULP away from edges with zero novel coverage and zero cracks away from edges, an exact written-pixel mask at identity, bit-identical adaptive output on all-fallback fields, and at least half of covered pixels compared and oracle-checked on plane fixtures; plane fixtures must agree with an independent double-precision plane oracle within 64 ULP with zero missing and zero unexpected coverage outside the footprint band, fade band and depth clip; translated fade fixtures must match the analytic Bayer fade mask exactly away from threshold ties. Edges are fixture-known discontinuities (steps, islands, sky, invalid; noise everywhere) plus the reference coverage border, never rendered-depth deltas, so slopes, fade and coarse/fine seams are judged. Timing retains every raw per-sample GPU duration and adaptive tile counters.

## Known limits and missing qualification

- Root's compile receipt covers milestone 1; the four repair gates after it (adaptive lease-on-acquire, probe writer leasing with in-place pool replacement, copy fade from the present head, pair token release) have not been compiled by anyone yet.
- The copy path is restricted to identical lattice and projection; a planar footprint reconstruction for mismatched lattices is not implemented, so those cases use the mesh.
- The system's display-time adjustment is not exercised by any harness; only headset runs with captured visual evidence can qualify it. The simulator pose fixture has no anchor.
- Adaptive tolerance of 16 ULP is an initial statement. The indexed fan reuses 33 evaluated vertices across the same 32 triangles; its parity and performance against the unindexed fan still require the source-bound GPU rerun.
- The paired producer is unproven; with it off or not ready, two-view drawables keep independent alternating eyes and the copy path is ineligible for them by design.
- Probe texture sets are bounded by count (4) and by an aggregate byte cap (default 384 MiB, `MUGUET_COMPOSITOR_ANCHOR_PROBE_MAX_MIB`); when a set would exceed it the probe halves its own analytic source resolution and logs the change. Game resolution is never touched by the probe.

## Post-GPU repair (same day)

Root's first GPU run (`target/verification/reprojection-implementation-v1/runs/root-final-batch-v1`, immutable) failed 7 of 30 fixtures. A CPU float32 emulation of the corner fit and the vertex chain against a Double oracle put every failing fixture's vertex math within 3 ULP of truth, so the 42 and 352 ULP GPU errors under camera motion are rasterizer sub-pixel vertex snapping times the screen-space depth gradient, zero at identity where fixtures passed. The harness now gates per pixel against the Double oracle with predeclared budgets (metric depth 0.1 mm for baseline and candidates, a 2^-8 pixel snapping model, exact masks, exact identity colour against source texels, predeclared accepted-tile counts, directly judged fan and seam pixels), excludes only the footprint band, Bayer ties and fixture-known edges, uses a square-pixel border fixture, asserts the candidate equals the live shader, writes a failing JSON on abort, and has no environment overrides for gates. Candidate-versus-baseline ULP is recorded as a diagnostic on oracle fixtures and remains a 4 ULP gate elsewhere. The probe now publishes a rendered pair only when its command buffer completes successfully, invalidates the set's generation on failure, keeps one render in flight, protects held and pending sets from rewrite, and evicts an idle set before allocating its replacement so the byte cap is never exceeded transiently. None of this has been compiled or run since the repair.

## Harness repair after GPU batch v2 (same day)

Root's second run (`runs/root-final-batch-v2`, immutable) failed 8 of 30 fixtures with the production shader unchanged and the legacy path exact. All eight were harness defects: the colour oracle compared source texel bytes where the mesh samples with a linear filter at scale 2 and 16; the depth bound used eight ULP of 0.02 as a global floor against a near-crossing plane at depth near 0.9; and the square-pixel 37x23 fixture widens the field of view until one output pixel spans about 30 mm of depth, so the 1/256 pixel snapping model predicts about 0.12 mm for every path including the baseline (measured 128 µm). The harness now samples an independent bilinear clamp-to-edge UNORM oracle (exact bytes at scale 1, within 1 LSB otherwise), bounds depth per pixel by eight ULP of that pixel's expected depth plus a gradient-based snapping term only under camera motion, rejects any written NaN, infinite or out-of-range depth, requires the adaptive tile-class readback to exist and match both the tile count and the counters on every fixture, keeps the original non-square border fixture and the square one as an extra, and reports three verdicts per fixture: baseline, candidate-absolute and candidate-relative. The run passes only when baseline and candidates pass; an inherited baseline failure is named as such and never folded into a pass. The 100 µm budget is unchanged; the square border fixture is expected to fail it for the baseline, which is a fixture property the rerun will confirm or refute. Nothing here has been compiled or run since the repair.
