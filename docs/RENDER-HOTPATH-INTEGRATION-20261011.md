# Rendering hotpath integration — October 11, 2026

The launcher’s existing experimental rendering-overhead choice now requests packed uniform snapshot reuse and the XR emission lock shortcut alongside the three existing draw-preparation optimizations. It remains off by default. Each diagnostic environment value `0` or `1` independently overrides the saved request. The op47 upload dedup experiment remains environment-only. No new native ABI or original game/AOT input change.

XR diagnostics cache only the optional environment override; a status probe before runtime startup must not freeze the launcher request to false. The existing typed pre-start setter owns the app request and cannot change it after initialization. Guest emission reads that atomic request only when no explicit override is present, with no environment lookup on the hot path. Uniform snapshot configuration is resolved once when the GPU state is created.
