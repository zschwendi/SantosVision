# Choose your V download

**Paid Apple Developer account required for the supported GTA / V IPA installation route (iPhone/iPad and Vision Pro).** The native Mac ZIP does not require a developer account.

| Device | Package | Instructions |
| --- | --- | --- |
| iPhone or iPad | [iOS 28.1 preview](https://github.com/zschwendi/avp-gta/releases/tag/ios-v28.1-preview) | [Windows/Linux installation](IOS-SIDELOADING.md); paid developer signing required |
| Apple Vision Pro | [visionOS preview](https://github.com/zschwendi/avp-gta/releases/tag/visionos-v30.1) | [Windows/Linux installation](SIDELOADING.md); paid developer signing required |
| Apple Silicon Mac, macOS 14.0+ | [Native Mac 30.1 preview](https://github.com/zschwendi/avp-gta/releases/tag/macos-v30.1-preview) | [Mac installation and import](MACOS.md) |

An ARM64 processor is only one compatibility requirement. iPhone/iPad share the iOS package; visionOS and macOS require their own packages. Windows and Linux can run the sideloading tool, but these Apple packages do not run as Windows/Linux games. Apple TV, Android and Intel Macs are not covered by these downloads.

All downloads are experimental and require your own supported game files. Check the release's OS, memory, signing and validation notes before installing.

The iPhone/iPad and Vision Pro packages above predate **build 31**, which adds V options and Play with friends to the iPhone/iPad and Vision Pro launchers. For what changed and how to build it from source, see [Build 31: V options and Play with friends](V31-LAUNCHER-MULTIPLAYER.md) and [V on iPhone and iPad](IPAD-IPHONE-SETUP.md).

Build 31 has no public download: its device builds embed compiled game code and a private signing profile. Build it from source with your own game files.
