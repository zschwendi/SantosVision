Actual native-game RGBA16Float contribution captures show that GTA also enlarges its lower-left HUD: the measured alpha bounds grow from 360×260 pixels at 2560×1440 to 576×417 pixels at 2560×2304. The scenes differ, so these captures support a HUD size check, not a sharpness comparison.

The former immersive canvas retained its 60-degree horizontal extent at either size. That enlarged these ordinary HUD elements by about 1.6 in angle and moved the lower edge down. For exactly the admitted 2560×2304 experimental format, the ordinary canvas now receives an isotropic 1440/2304 scale before the existing safe-area placement. Its vertical reading frame returns to the existing 1440-line size; its outside anchors move inward. Pixel aspect and the complete source UV range are retained. No alpha is inferred or reconstructed.

Every existing 16:9 format retains exactly the former geometry and output. Native scope geometry retains the former extent at both resolutions. The flat window, source game pixels, renderer world projection and resolution defaults are unchanged. The source-size check uses the dimensions of the same leased HUD texture; it does not consult current settings or another frame.
